# Draw.io Skill 功能总览

本目录依据本机安装的 drawio-skill 2.1.0 自动生成。完整原始说明见 `04_skill完整副本/SKILL.md`。

## 输出与编辑能力

- 生成可编辑 `.drawio` XML；导出 PNG、SVG、PDF、JPG。
- PNG/SVG/PDF 可嵌入原始图表，重新用 Draw.io 打开继续编辑。
- 支持流程图、架构图、UML、ERD、BPMN、SysML、网络拓扑、云架构、ML/DL、C4、泳道等。
- 支持官方 10,446 个 shape，以及独立的 AI/LLM 与数据系统 SVG 图标集合。
